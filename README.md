# 耀丁音乐 · 车机英语听歌播放器

一个为**老车机**设计的英文歌学习播放器：把 U 盘里的 MP3 和同名 LRC 歌词读进来，逐句跟读、单句循环、变速不变调。

纯静态单文件，无框架、无构建步骤、无后端。目标是安卓 6–10 的老车机浏览器（WebView）也能流畅跑。

在线地址：<https://english-song-player-53251.app.workbuddy.host/?sharecode=4RG3JT7QBE>

---

## 为什么做这个

车机自带的音乐播放器只能"整首循环"，学英文时最需要的三件事一个都没有：

- 听不懂的那半句没法反复听
- 语速不能放慢
- 中文译文要么不显示，要么和原句挤在一起

所以做了一个"只剩歌词"的播放器：其余界面全部 5 秒后自动隐藏，副驾也能看清。

## 功能

### 播放与跟读

| 功能 | 说明 |
|---|---|
| 逐句歌词 | 当前句加粗提亮，自动滚动居中，点任意一行跳到该句 |
| 切句与切歌 | 内侧两个按钮切上一句/下一句，外侧小的两个切上一首/下一首，切歌保持播放状态并从头开始 |
| 单句循环 | 反复磨一句，直到听懂 |
| A-B 循环 | 自己框住任意片段反复听 |
| 变速不变调 | 0.6 / 0.75 / 0.9 / 1.0 / 1.15 / 1.3 倍 |
| 单曲循环 | 整首反复 |
| 随机播放 | 下一首随机挑、且不会连着重复；上一首按播放历史回退 |
| 中英双语 | 译文可一键隐藏：先硬听，卡住了再看 |
| 夜间 / 日间主题 | 夜间纯黑护眼；日间米白底深字，强光下更清楚。可手动切换，也可按时间自动 |
| 进度记忆 | 每首歌单独记住播到哪儿 |

### 界面

- **沉浸模式**：5 秒不操作，进度条和所有按钮淡出，只剩歌词与歌名
- **控件唤出**：碰一下屏幕回来，第一下只唤醒不跳句
- **歌名常驻**：左上角显示英文歌名 + 中文译名，沉浸模式也不隐藏
- **全屏**：首次触碰自动进全屏；也支持添加到主屏幕以独立窗口启动
- **字号自适应**：按屏幕宽度分档，全曲统一字号，超长句才折行

### 数据

- **本机缓存**：选过的歌（音频 + 歌词）存进浏览器 IndexedDB，关掉再打开自动恢复上次那首、上次的位置
- **进度/设置持久化**：速度、译文开关、每首播放进度存在 localStorage

## 使用

### 车机 / 手机

1. U 盘（FAT32）里放 `歌曲.mp3` 和同名的 `歌曲.lrc`
2. 车机浏览器打开上面的链接
3. 点屏幕任意位置 → 进全屏 → 点「选歌」，定位到 U 盘，把 mp3 和 lrc 一起选中
4. 一次缓存完成后，以后打开不用再选

建议一个目录一个目录地选（Android 文件选择器一次只能选一个目录下的文件），选完会累加，不会覆盖。

### 添加到主屏幕（推荐）

- **Android Chrome**：菜单 ⋮ → 添加到主屏幕
- 装完从图标启动，没有地址栏和标签栏，直接全屏

### 桌面浏览器

打开链接即可，支持键盘：`空格` 播放/暂停，`←` `→` 上/下一句。

## 歌词格式

支持三种双语写法，任选其一，**不需要准备两个文件**。

### 写法 A：同一时间戳写两行（推荐）

```
[ti:Love Story]
[ar:Taylor Swift]
[00:16.06]We were both young when I first saw you.
[00:16.06]当我第一次见到你时，我们都还年轻
```

### 写法 B：同一行用斜杠分隔

```
[00:16.06]We were both young when I first saw you. / 当我第一次见到你时，我们都还年轻
```

### 写法 C：中文另起一行、不带时间戳

```
[00:16.06]We were both young when I first saw you.
当我第一次见到你时，我们都还年轻
```

### 规则

- 时间戳格式 `[mm:ss.xx]`，两行的时间戳必须**完全一致**（差 0.03 秒内都算同一句）
- 时间戳标在"这句开始唱"的时刻
- 编码 UTF-8 或 GBK 都行，程序会自动探测
- `[ti:]` 里可以写中文译名：`Love Story / 爱情故事` 或 `Love Story（爱情故事）`，会显示在左上角
- 纯英文、纯中文的单语歌词也能正常播

## 本地运行

没有任何依赖，直接开文件就能看（`file://` 下本机缓存不可用，其余功能正常）：

```bash
# 方式一：直接打开
open index.html

# 方式二：起个本地服务（要测本机缓存必须这样）
python3 -m http.server 8000
# 然后访问 http://localhost:8000
```

### URL 参数

| 参数 | 作用 |
|---|---|
| `?demo=1` | 自动加载演示曲，跳过说明弹窗 |
| `?focus=1` | 预留（沉浸模式已是默认） |

## 技术说明

### 为什么是单文件网页而不是 App

- 老车机上迭代 App 的成本很高：打包 → 拷 U 盘 → 插车机 → 安装，一轮五分钟
- 网页改完刷新就能看，一天能迭代几十个版本
- 装 APK 反而是最后一步：当需要离线、后台播放、直接读 U 盘目录时再包壳

### 关键实现

| 问题 | 做法 |
|---|---|
| 老内核兼容 | 纯 ES5 语法，不用框架、不用构建，`index.html` 打开就能跑 |
| 歌词字号 | 按视口宽度分档给基准字号，再按全曲 97% 分位统一缩放；字号有 22px 下限，宁可折行不压字 |
| 加粗导致折行 | 测量行宽时临时按 600 字重测量，避免"平时刚好一行、唱到变粗就折行" |
| 隐藏控件时歌词跳动 | 只做淡出，不收起布局，否则每次隐藏当前句都会重排跳一下 |
| 缓存音频 | IndexedDB 存 Blob，逐首 FileReader → Blob 写入，带进度提示 |
| 全屏 | 浏览器禁止加载即全屏，改为首个触摸手势触发；同时提供 PWA 清单，从主屏图标启动即无边框 |

### 不支持的能力及原因

| 做不到 | 原因 |
|---|---|
| 页面加载即自动播放 | 浏览器要求必须由用户手势触发音频 |
| 记住 U 盘里的文件路径 | 网页无权访问本地文件系统，只能整份缓存到浏览器存储 |
| 在网页里读目录 | 同样受沙箱限制，需要 APK 才能扫目录 |

## 已知问题

- **手机浏览器开着「桌面版网站」时整页会变得很小**：页面会检测到并在顶部提示，按提示关闭即可
- **车机浏览器关机可能清空本地数据**：部分车机浏览器关机即清缓存，那样本机缓存会失效，只能走 APK
- **部分国产浏览器不支持 PWA 清单**：主屏图标可能回退成字母，这不影响使用
